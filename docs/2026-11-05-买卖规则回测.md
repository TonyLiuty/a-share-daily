# 买卖规则与历史回测（2026-11-05）

这份记录是研究结果，不改变 1.0.0 生产策略，也不产生交易指令。历史行情缺口已通过腾讯财经前复权日线接口补齐，并落在本机缓存，不进入仓库。

## 规则

- 买入：信号日收盘后，下一交易日开盘买入。信号日之后的数据不参与买入判断。
- 卖出顺序：盘中先触发止损（入场价下跌 8%），再触发止盈（上涨 12%）；持有至少 5 个交易日后，收盘价跌破 MA20 卖出；其余情况最多持有 20 个交易日，到期按收盘价卖出。
- 同一根 K 线同时触发止损和止盈时按止损成交，避免用日线无法确定的盘中顺序制造乐观结果。
- 成本敏感性：在毛收益上分别扣除单次往返 5、10、20bp。组合按每个信号等权统计，不复利，不把重叠持有期拼接成净值曲线。

## 数据与基线

信号文件包含 310 条记录、75 只股票、30 个信号日。每只股票的历史 K 线由腾讯 `fqkline` 前复权日线接口按代码补取，原始响应保存在 `quant-agent-output/research/kline-cache/`，回测脚本为 `scripts/backtest_signal_exits.py`。

原有固定持有期评估仍以 `scripts/evaluate_research.py` 为基线；本规则回测只比较买卖时点，不替换原有收益字段，也不调整动量、趋势、量价、风险、估值权重。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 完成交易 | 300 |
| 覆盖信号日 | 30 |
| 毛收益均值 | -0.941% |
| 胜率 | 31.0% |
| 止损 / 止盈 / 跌破 MA20 / 到期 | 39 / 16 / 191 / 54 |
| 扣 5bp 后均值 | -0.991% |
| 扣 10bp 后均值 | -1.041% |
| 扣 20bp 后均值 | -1.141% |

这组规则在当前样本中没有通过“绝对收益为正”的验收条件，不能升级为生产卖出规则。结果支持的判断是：**当前信号池更常见的退出原因是跌破 MA20，止盈触发少；固定的 8% 止损与 12% 止盈没有把这段样本的平均收益转为正数。** 后续应先扩大时间跨度并做时间顺序样本外验证，再比较行业约束和不同退出参数。
