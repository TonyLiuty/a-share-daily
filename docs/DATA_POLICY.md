# 数据与研究口径

- 仅提交程序、文档和测试。真实报告、候选、财务、历史信号、浏览器资料、凭据和缓存不随源码发布。
- 行情来自第三方公开接口，完整性、复权方式和可用性可能变化。样本成交额不是全市场成交额，也不是资金净流入。
- 固定研究样本单独记录覆盖率，不替代原策略股票池。行业5/20日收益必须有完整同源交易日快照；缺失时不计算。
- 信号在盘后生成，理论建仓价使用下一交易日开盘，收益扣除配置中的费用与滑点。重叠信号不是独立样本。
- 新闻读取成功不等于事实已核验。自动页面匹配仍需人工审阅，盘后新闻不能解释此前的收盘表现。
- 不下载或复制新闻全文到发布仓库，不对第三方数据授予再分发许可。
- 没有提供实盘执行、收益保证或自动调参功能。
