# 官方行业表采集基准

## 目标与验收

历史候选资料不能覆盖全部可评分股票。目标是用批量原始行业表扩展覆盖，并记录取得时间、来源和文件hash，使实验能验证资料时点。成功条件是31个申万一级行业全部下载、每张表的标签与请求行业一致、六位证券代码保留前导零、原件不被覆盖、跨行业冲突保持未知。缺表、字段不符或代码不合法时停止，不生成可用的导入JSON。接口、传输方式与文件组织可调整；实际采集日期与历史时点约束固定。

## 来源与实现

申万官方行业分类下载页提供31个一级行业及对应分类表[^sw]。`scripts/fetch_industry_master.py`逐表下载XLSX，归档原件、请求URL、逐文件SHA-256、北京时间取得时间及最终完成时间。下载目录使用实际执行时间，已存在目录拒绝覆盖。`计入日期`只作为供应商字段保留，`observed_date`使用最后一张表取得后的实际日期。

下载支持requests及原生curl。两者均验证HTTPS证书，curl适用于使用Windows系统证书库的环境；不关闭证书验证。依赖通过`requirements-mapping.txt`安装。原始表和导出数据保留在本地输出目录，不提交到公开仓库。

覆盖审计输出使用排他创建，已有文件拒绝覆盖，防止误将原始CSV路径作为审计输出。重复审计需提供新的输出文件名。

## 实际结果

2026-10-26 14:44:14至14:46:12（北京时间）取得行业清单和31张分类表，共32个原件。表内共5,372行、5,275个唯一证券代码；5,191个分类无冲突，84个代码在同日取得的表中有不同分类，保留未知。无冲突占资料代码的98.41%，这个分母不是全市场股票数。原始CSV SHA-256为`60b2412143caeef81bcce637d96e550a318ee68fefc3d81a1ab7c8d40735eb76`。

将上述资料与2026-10-20保存的1,000只行情代码比对，983只分类明确、12只冲突、5只缺失，覆盖率98.30%。这是当前资料对旧代码清单的覆盖检查，不是历史可得性检查。不能将结果写回2026-10-20选股，也不能用它声称收益改善。

真实时点检查使用该归档的10只候选代码：以2026-10-26为信号日，全部当前映射被拒绝；以2026-10-27为信号日，10个代码可映射。没有生成实验信号。实验仍要求评分母集100%映射并选足10只，每个一级行业最多2只；当前1,000只清单仍不能通过完整覆盖条件。下一步应核对84个冲突代码的官方有效成分与变更记录，保留核对证据后再补齐资料，不按旧表的计入日期自行推断现行分类。

## 复现

```powershell
python -m pip install -r requirements-mapping.txt
python scripts/fetch_industry_master.py --transport curl --output ./quant-agent-output/research/industry-master
python scripts/audit_industry_master.py --master <采集目录>/industry_master.json --snapshot ./quant-agent-output/daily/2026-10-20/market_snapshot.csv --output ./quant-agent-output/research/industry-coverage.json
```

`industry_master.json`可通过`run_daily.py --industry-policy sw-primary --industry-master <采集目录>/industry_master.json --output ./experiment-output`用于独立实验。新取得的表最早从下一日使用，不补写历史。生产默认版本、因子权重与已有信号保持不变。
