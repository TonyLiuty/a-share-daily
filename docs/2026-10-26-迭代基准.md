# 行业展示与量化评估迭代基准

## 目标与验收

目标是让读者从行业直接找到公司，并识别行业约束与收益评估的数据缺口。原假设是：严格区分公司行业和行情板块、只统计完整信号日，可以减少错误归因与缺样本产生的偏差。当前可变项包括页面排序、卡片布局和质量阈值；生产评分权重保持1.0.0。

可用条件：每只观察股出现在一个可点击行业分组；正收益榜尾不写成领跌；原始缺失不填零；质量检查能拒绝全未分类、混合行业体系和超限样本；收益基准只使用同日全部记录成熟的样本；额外成本能复算。若通过弱化断言、猜测行业归属或填补收益才能通过，则否决该改动。

## 原行为与修改

| 场景 | 原行为 | 当前行为 |
|---|---|---|
| 行业到个股 | 主要依赖长表与股票详情 | 按公司行业分组，每只股票可跳转详情 |
| 同名板块 | 可能按名称匹配其他分类的涨跌 | 行情板块与公司行业分别展示 |
| 正收益榜尾 | 写成领跌 | 写成涨幅靠后 |
| 行业全未分类 | 跳过行业上限 | 报告显示无法核实；可选严格模式停止新信号 |
| 收益缺失 | 只平均已有股票，分母变化 | 研究基准单列不完整日期，仅完整日参与均值 |
| 浏览器测试 | 固定8条消息和某个股票代码 | 按输入Markdown的实际事件和股票数量验收 |

严格模式的输入还要求显式、统一的行业分类体系和层级。现有上游缺少该元数据，行业映射补齐前严格模式不会通过。诊断模式不会修正已有集中名单。
