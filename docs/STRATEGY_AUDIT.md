# 量化选股策略审计

审计范围：`scripts/run_daily.py`、运行输出目录的 `config.json` 及已有的数据口径文档。审计只读代码和本地样本，不调整权重、不补抓数据。

## 结论

后续进展（2026-10-26）：下文审计描述的默认1.0.0策略行为保留，未静默替换生产。独立1.1.0实验已增加选股前申万一级映射、每行业2只和完整覆盖检查；当前仍存在行业冲突与缺失，不能直接升级生产。研究评估已按完整信号日聚合并增加成本敏感性、重复记录和混合版本校验，原生产权益曲线未重写。原件一致性见[验收记录](2026-10-26-行业原件一致性验收.md)，覆盖缺口见[采集基准](2026-10-26-官方行业表采集基准.md)。

当前程序可以稳定地产生一个“高流动性股票中的技术观察池”，但还不能把它称为行业约束有效、样本口径一致且已经验证稳定的选股策略。最严重的问题是行业分散约束在新浪降级路径下被程序主动放开；其次是行业字段获取在选股之后才补充，导致即使基本面接口有申万行业，也无法参与本轮分散。收益统计的入场和持有日定义基本清楚，但有效样本、重叠信号、缺失收益和数据源变化没有形成足够严格的可比性标记。

## 已核实的流程

1. `fetch_snapshot_with_fallback()` 先请求东方财富快照；失败后使用新浪成交额排序样本。新浪快照把 `industry` 固定为“未分类”，并且 `return_60d_snapshot` 设为缺失。
2. `preliminary_filter()` 先按名称、价格、成交额、市值和代码段过滤，再以当批横截面排名计算预选分：流动性 35%、60 日表现 30%、换手率适中 15%、正 PE 估值 10%、当日涨跌不过激 10%，取前 140 只。
3. 对 140 只下载约 180 根前复权日 K 线，至少 125 根有效数据才进入因子评分。最终动量、趋势、量价、估值和风险五项仍是当批横截面分位数或规则分。
4. `diversify()` 在公司资料和申万行业抓取之前执行，只读取快照中的 `industry`。行业为空时把上限设为候选数，随后最多取 10 只，因此配置中的 `max_per_industry=2` 在该路径上没有约束力。
5. 当前信号在盘后写入；收益以信号日之后首个交易日开盘为入口，分别取第 1、5、20 个交易日收盘，减去两次单边费率和配置的往返滑点。收益成熟后更新历史信号和权益曲线。

## 问题与影响

### P0：行业分散约束会失效

证据：新浪快照将全部行业设为“未分类”；`diversify()` 对“未分类”使用 `cap=count`。代码注释已经承认这是为避免候选不足而放开的行为，但结果是银行、能源或其他同质资产可能占据大部分观察池。2026-10-14、2026-10-15 报告出现多只银行股，正是该失效的可见后果。

影响：组合集中度、行业暴露和收益波动被低估；报告中的行业分布不能代表策略执行了行业约束。

执行建议：

- P0-1：把行业字段变成选股前的必需字段。主快照没有可靠行业时，先使用同源、可回溯的本地行业映射或一次性行业批量接口；映射覆盖不足时停止生成正式信号并返回 `data_error`，不要静默放开上限。
- P0-2：在 `diversify()` 前固定 `industry_source`、覆盖率、空值数和映射版本；候选 CSV 同时保存 `industry` 与 `industry_source`。
- P0-3：分散规则按统一行业层级执行，并额外输出一级行业 HHI、最高行业占比和未分类占比。分散失败时报告明确标红。

### P1：预选排名在数据源降级时改变含义

新浪降级时 60 日快照表现缺失，预选分中的 30% 实际变为中性填充值；PE 缺失也以中性排名参与。新浪股票池是按当日成交额截取的高流动性子集，东财路径和新浪路径的股票成员、字段质量与行业体系不同。

影响：同一配置在两种数据源下并非同一策略；140 这个数量也不是全 A 股固定排名。跨日比较候选数、成交额、行业和收益时，数据源切换会混入口径变化。

执行建议：

- P1-1：保存 `snapshot_source`、原始覆盖数、过滤后数量、每个预选因子有效率和缺失率；任何核心预选因子有效率低于阈值时，报告标记“不可与主源日比较”。
- P1-2：把“预选排名”与“最终评分”拆成两套可审计字段，保留原始数值、排名分母和分位方向；对全缺失列禁止伪装成有效信号。
- P1-3：建立固定研究样本只用于跨日诊断，策略信号仍保留当日流动性样本；报告中分别展示覆盖率，禁止把两者合成一条收益曲线。

### P1：最终因子评分是横截面相对分，不是稳定的绝对信号

动量、回撤、波动率、流动性、PE/PB 等大量使用当日候选集的 `rank(pct=True)`。候选集变为新浪 1000 只或东财 700 只时，分数的参考分布随之变化；缺失估值默认 50 分，缺失的预选 60 日表现也默认中位分。评分权重目前是人工配置，尚无样本外证据证明最优。

影响：报告里的 80 分只表示“在当天可评分股票中靠前”，不表示未来收益概率；源切换和极端样本会改变排名。

执行建议：保存每个因子的有效样本数、分位数边界和缺失占比；对缺失核心因子设置降级标签或剔除；用滚动时间切分的样本外评估比较因子单项、等权和当前权重，评估前冻结参数。

### P1：收益评估可用于研究，但有明确统计边界

已做对的部分：入口使用信号日后的下一交易日开盘，避免用信号日收盘成交；1/5/20 日窗口按交易日推进；历史信号不成熟时保持缺失；费用和滑点单独扣除。

需要修正的边界：

- 权益曲线按信号日把有收益的股票简单平均。部分股票 K 线缺失时，实际参与平均的股票数会变化，且没有最低覆盖率门槛。
- 同一股票可跨日重复入选，重叠窗口之间并非独立观测；当前虽在文档提示，但胜率、均值和标准差仍容易被读者按独立样本解读。
- 基准收益按每条信号记录重复写入，再按行平均；数值通常等价，但应改为每个信号日一条基准记录，避免重复加权的误解。
- K 线主源为腾讯前复权，失败时新浪不复权。跨除权区间时信号、均线和收益不再同口径；报告已有提醒，但未把受影响记录排除或单独统计。
- 没有交易成本敏感性、组合换手、容量和停牌/涨跌停可成交性检验，因此“理论收益”不能直接解释为可实现收益。

执行建议：对每个信号日保存 `eligible_count`、`return_count` 和覆盖率；低于阈值时该日收益记为缺失，不纳入权益曲线。统计同时给出按信号日聚合的组合结果、按股票信号聚合的结果和去重后的股票/日期数量。复权源变化时分组报告并暂停合并。

## 优先级路线

| 优先级 | 工作项 | 验收证据 |
|---|---|---|
| P0 | 选股前完成同源行业映射；覆盖不足时阻止正式信号 | 降级样本不再出现 7 只同业集中；日志与 CSV 有来源、覆盖率、映射版本 |
| P0 | 增加硬数据质量门槛 | 缺核心字段时状态为 `data_error` 或明确降级，不用中性分掩盖 |
| P1 | 固化预选/最终评分的分母、有效率和源版本 | 两种数据源运行结果可解释，报告能判断是否可跨日比较 |
| P1 | 收益按信号日覆盖率聚合并拆分重叠样本 | 权益曲线有覆盖率列，重复信号与独立信号分开 |
| P2 | 时间滚动样本外评估与成本敏感性 | 至少训练、验证、测试三段；冻结权重后报告超额、回撤、换手、容量 |
| P2 | 以行业为入口重做展示 | 行业页先列行业涨跌、估值和标的，再列个股因子与风险，行业字段与选股字段同源 |

## 下一轮迭代的否决条件

若行业覆盖率低于设定阈值、核心预选字段缺失率过高、或收益结果只在单一源/单一成本假设下成立，则保留“观察池”定位，不宣称策略稳定。只有在固定口径的样本外区间中，超额、回撤、覆盖率和换手同时通过预设门槛后，才考虑调整权重或扩大候选范围。
